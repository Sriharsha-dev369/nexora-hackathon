# Issue Tracker

**Type:** GitHub Issues (via `gh` CLI)

Issues for this repo live in GitHub Issues. Skills (`to-tickets`, `triage`, `to-spec`, `implement`) create/read/update issues with `gh issue create`, `gh issue list`, `gh issue view`, `gh issue edit`, etc.

- PRs-as-request-surface: **off** (triage does not pull open PRs into the queue)
