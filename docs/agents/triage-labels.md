# Triage Labels

| Role | Label |
|---|---|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

These are created as GitHub labels on the repo (`gh label create ...`) the first time `triage` runs, if they don't already exist.
